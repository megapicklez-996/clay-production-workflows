# Transcript Lessons

- Parity covers sources, eligibility, enrichment, copy, Audience writes, CRM,
  sequencer behavior, and reconciliation—not a visually similar graph.
- Start with one or two rows and an explicit credit ceiling.
- Check title, LinkedIn URL, and other required values in the final payload even
  when upstream enrichment reports success.
- Record whether an outcome was automated or manually repaired.
- A proof Audience should contain the same person verified downstream.
- Multi-contact accounts need durable person work items.
- Existing sequencer leads must be suppressed or reused without delete/re-add.
- A request to run the remaining audience is a launch-gate question, not approval.
- A completed Clay run does not prove CRM and sequencer agreement.
